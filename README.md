# Carrinho de compras

Aplicação web simples para praticar lógica de programação com JavaScript. Ela permite escolher um produto, informar a quantidade e acompanhar os itens e o valor total do carrinho.

## Funcionalidades

- Adicionar ao carrinho um dos produtos disponíveis: fone de ouvido, celular ou Oculus VR.
- Calcular o subtotal com base na quantidade informada.
- Atualizar o total do carrinho.
- Limpar os produtos e zerar o total.

## Como executar

Não é necessário instalar dependências. Abra o arquivo `index.html` em um navegador. Se preferir, use a extensão **Live Server** do Visual Studio Code para servir o projeto localmente.

## Tecnologias

- HTML
- CSS
- JavaScript
